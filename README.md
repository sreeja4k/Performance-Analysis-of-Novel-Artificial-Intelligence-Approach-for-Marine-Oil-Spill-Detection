# Marine Oil Spill Detection Using Artificial Intelligence

# Project Overview

This project focuses on detecting marine oil spills using Artificial Intelligence (AI) and Vision Transformers (ViT) with satellite imagery.

The objective is to support the identification of marine oil spills and contribute to ocean environmental monitoring.

# Technologies Used

Artificial Intelligence (AI)

Machine Learning (ML)

Vision Transformers (ViT)

Satellite Image Processing
